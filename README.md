# MASTER GAMES

বাংলা ভাষার মোবাইল-প্রথম, অফলাইন কার্ড ও বোর্ড গেম সংগ্রহ।

## গেমসমূহ
- **Teen Patti** — ৩ কার্ডের হাত তুলনা; Trail, Pure Sequence, Sequence, Colour, Pair ও High Card।
- **Poker** — ৫ কার্ড Draw Poker; কার্ড বদল, পূর্ণ hand ranking ও tie-break।
- **Indian Rummy** — ১৩ কার্ড, দুই ডেক, Wild Joker, discard pile, pure/impure sequence এবং set validation।
- **Hazari** — ৪ খেলোয়াড়, ১৩ কার্ডকে ৩-৩-৩-৪ ভাগ, চারটি comparison round, কার্ড পয়েন্ট এবং ১০০০ পয়েন্টের ম্যাচ।
- **Call Bridge** — ৪ খেলোয়াড়, ১৩ trick, spade trump, follow-suit, bidding ও contract score।
- **Ludo** — ২–৪ খেলোয়াড়, প্রতি খেলোয়াড় ৪টি গুটি, dice, safe square, capture ও home lane।

## অ্যাপের সুবিধা
- বাংলা UI এবং Android-এ Home Screen-এ ইনস্টলযোগ্য PWA।
- Service Worker দিয়ে অফলাইন ক্যাশ।
- Emerald Gold, Ocean Blue ও Royal Purple থিম।
- ফোনের গ্যালারি থেকে ব্যাকগ্রাউন্ড ছবি বেছে নেওয়া।
- বাংলাদেশ সময় ডিফল্ট; রিয়াদ সময় বা দুই সময় একসঙ্গে দেখানো যায়।
- ঐচ্ছিক সাউন্ড ইফেক্ট।
- ভার্চুয়াল পয়েন্ট/৳ চিহ্ন কেবল গেমের ভেতরের স্কোর; কোনো বাস্তব টাকা, জমা বা উত্তোলন নেই।

## Android-এ ইনস্টল
1. Chrome-এ অ্যাপের ওয়েব ঠিকানা খুলুন।
2. Chrome-এর ⋮ মেনুতে **Add to Home screen** বা **Install app** নির্বাচন করুন।
3. MASTER GAMES আইকন Home Screen-এ যোগ করুন।
4. প্রথমবার অনলাইনে খুলে ক্যাশ তৈরি হলে পরবর্তী সময়ে অফলাইনেও চালানো যাবে।
